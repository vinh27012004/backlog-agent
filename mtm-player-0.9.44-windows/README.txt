MTM PLAYER 0.9.44
Open mtm-player.exe without arguments. Select the team workspace on Manage or Init. See app/docs/installation.md for setup instructions.
Requires Windows, PowerShell 7, and a supported authenticated CLI provider.
Node.js is NOT bundled. Copy node.exe from Node.js 24 LTS for Windows x64 (minimum Node.js 20) into this folder, next to mtm-player.exe.
  Download: https://nodejs.org (Windows Binary .zip, take node.exe from it), or copy it from an installed Node.js, e.g. C:\Program Files\nodejs\node.exe
Codex desktop and an MTM Player plugin are not required.
